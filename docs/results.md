# Reported project results and limitations

The following figures describe the private internship project and are provided as portfolio context. They are not reproduced from private data in this repository.

| Item | Reported result |
| --- | ---: |
| Reviewed data asset | 67 rooms / 790 valid windows |
| V5 training set | 42 rooms / 501 windows |
| New singing-room comparison | V4 4/12 → V5 12/12 |
| Five newly collected rooms | V4 44/60 → V5 52/60 windows |
| Room-level result in that comparison | V4 3/5 → V5 5/5 |
| Tested Linux GPU latency | approximately 1.5–2.1 s per 15-second window |

## Interpretation limits

- Five rooms are too few for a general production accuracy claim.
- The comparison is best treated as exploratory regression evidence.
- Long-running reliability and multi-room throughput require separate testing.
- Entertainment subtypes and mixed-content rooms remain challenging.
- A final sealed blind-test result was not used in the public claim.
