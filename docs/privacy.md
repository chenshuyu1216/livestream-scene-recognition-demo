# Privacy and publication policy

This repository must not contain:

- real livestream video, audio, chat messages or streamer identities;
- signed or expiring media URLs;
- employer source code or internal interface definitions;
- server addresses, database credentials, API tokens or SSH material;
- private model artifacts or datasets with unclear redistribution rights;
- absolute paths from a contributor's workstation.

Synthetic examples should be used for demonstrations. Real deployments should establish consent, retention, access-control and deletion policies before collecting data.
